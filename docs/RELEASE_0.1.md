- 專案子路徑啟動，正常流程沒有第三方資源請求。
- 重新整理保留答案、信心與筆記；類HTML筆記不會被執行。
- 頁面內確認／取消交卷、連按兩次不重複提交、結果深連結重新載入。
- 完整JSON匯入預覽及合併；格式錯誤不覆寫現有紀錄。
- 全部32题逐題在390px手機視窗呈現並作答；8段程式的畫面與複製文字一致；2張圖表解碼與放大。
- 320px窄螢幕、844px橫向及768px平板重排，保留筆記且頁面沒有水平溢出。

- 兩個分頁同時寫入：拒絕較舊版本，不覆蓋另一分頁的練習。
- 停用JavaScript時顯示啟用說明，不顯示不能運作的交卷按鈕。
- 正常流程沒有未捕捉的瀏覽器JavaScript錯誤。

已人工檢視同一應用程式版本的手機首頁、手機程式題、圖表放大截圖。程式與放大圖片可在各自區域橫向捲動；固定底部導覽在全頁截圖中仍位於首個視窗底部，不代表下方內容不能捲到。

## 驗證限制

本地Chromium受到受管環境政策限制，URL導航回傳ERR_BLOCKED_BY_ADMINISTRATOR。未修改或繞過政策；以上完整HTTP／IndexedDB測試是在GitHub Actions標準runner執行。

手機尺寸模擬不等於實體Android測試。以下仍未驗證或未實作：

- 實體Android與系統返回鍵、背景回收、原生分享／檔案儲存。
- iOS Safari/WebKit、Firefox、TalkBack完整可及性驗收。
- Android APK打包、簽章、商店上架。
- 完整離線包與Service Worker、即時Python、AI API、自動跨裝置同步。
- 全科題庫、完整正式模考，以及正式考試難度／通過率校準。
- 公開Pages網站上的實際部署驗收。

內容為原創整理及AI協作，非iPAS官方審題或獨立專家認證。結構、算術與程式測試不等於題目絕對無誤。

## 第一輪試用

先做4～8題確認自己的手機操作與保存，再擴充題量。題庫不足會明示；已見題可複習，不冒充未見驗收。題目有疑義時，使用回報範本保留題目ID與版本，修正不能靜默覆寫歷史。
