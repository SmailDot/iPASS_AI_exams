# 0.1.0 實作與驗證紀錄

日期：2026-10-05。網站原始碼與自動檢查已建立。所有測試資料為合成，不是使用者紀錄。

## 驗證原則

本地初稿曾通過19項Node規則／備份測試、8道程式輸出與6項獨立算術斷言，以及靜態建置。其後重新整理的GitHub版本以該次commit的CI結果為準，不能拿初稿的成功代替新版本驗證。

本地Chromium受到受管環境政策限制，URL導航回傳ERR_BLOCKED_BY_ADMINISTRATOR。沒有修改、移除或繞過政策。完整HTTP／IndexedDB端到端測試交由GitHub Actions標準runner執行。

`tests/browser.py`包含32題手機呈現、8段文字程式與複製、2張圖表的解碼及放大、交卷取消及重複提交、重新整理、JSON匯入、故障圖片、保存失敗及多分頁衝突。只有CI顯示成功才可宣稱通過。

## 尚未驗證或未實作

實體Android、iOS Safari/WebKit、Firefox、TalkBack完整可及性、APK打包簽章、商店上架、完整離線包、即時Python、AI API、全科題庫和正式難度校準。

內容为原創整理及AI協作，非iPAS官方審題或獨立專家認證。以來源定位、結構、算術和程式契約檢查降低錯誤，不宣稱題庫絕對無誤。
