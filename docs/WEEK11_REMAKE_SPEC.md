# 規格書：iPAS 科目三練習站（補交第五週：用 Vibe Coding 做互動網頁）

## 1. 作品概述
- 名稱：學習步調 · iPAS 科目三練習站
- 類型：單頁互動網頁（單一 `index.html`，CSS 與 JavaScript 內嵌），免登入、資料只存在使用者瀏覽器。
- 目標使用者：準備 iPAS 中級機器學習技術與應用科目三的學生，想做有解析、可回顧的自測。
- 非目標：不是官方網站、不是正式模考、不預測通過率、不做帳號與雲端同步。

## 2. 核心功能（既有）
| 功能 | 說明 |
|---|---|
| 今日練習 | 依設定的時間（15／30／60／120 分鐘）與單元，自動選出一組題目。 |
| 作答與信心標記 | 每題可選選項，並標記「有把握／不確定／猜測／不會」。 |
| 交卷與解析 | 交卷後鎖定紀錄，逐題顯示正解、每個選項的解釋與來源。 |
| 讀碼題 | 8 題附 Python 程式文字，可複製；參照結果已預先驗證。 |
| 圖表題 | 2 題附必要圖片，載入時檢查 SHA-256 與解碼結果，失敗的題目不計錯。 |
| 學習紀錄 | 每次練習完整保留，首次作答與重做分開統計。 |
| 備份與還原 | 匯出 JSON 備份；匯入前先校驗並預覽，不靜默覆寫同 ID 的不同內容。 |

## 3. 本次新增功能：錯題重練
- 入口：學習紀錄 → 某次練習的逐題解析頁 →「只重練做錯的題」。
- 規則：
  - 只納入「有效且答錯」的題目（技術無效題與答對題不納入）。
  - 沿用同一個題目 ID，但選項順序重新隨機排列。
  - 重練會建立一筆新的練習紀錄，**原本的紀錄不被覆寫**。
  - 若該次沒有錯題，顯示「這份紀錄沒有可重練的錯題」，不建立空白練習。
  - 若目前已有未交卷的練習，先顯示提示，不會覆蓋進行中的練習。
- 目的：讓做錯的題在不同選項順序下再確認一次，避免只背住答案位置。

## 4. 資料與儲存
- 儲存位置：瀏覽器 IndexedDB（資料庫名稱 `smaildot.ipas.l23`）。
- 寫入採用版本號比對：另一個分頁已保存較新紀錄時，本頁會拒絕寫入，不會覆寫。
- 儲存失敗時，畫面會明確顯示「尚未安全保存」，並提供匯出目前內容的按鈕。
- 題庫以 SHA-256 指紋檢查，題目內容與紀錄不一致時不計入學習證據。

## 5. 作答規則（摘要）
- 作答以選項 ID 計分，不以顯示的字母計分。
- 有輔助（提示、閱讀短課）的作答不算閉卷證據。
- 技術無效（例如圖片載入失敗）不扣分，也不算作答錯誤。
- 不提供生成式 AI、追蹤分析、付費 API 或通過率預測。

## 6. 技術架構
- 前端：原生 HTML／CSS／JavaScript，無框架、無外部 CDN。
- 單檔版本：`scripts/build-single.mjs` 把題庫、模組與圖片（以 data: URL 內嵌）打包成單一 `index.html`，指令為 `npm run build:single`，輸出在 `dist/single-file/index.html`。
- 內容安全政策：單檔版本的 CSP 允許內嵌腳本與 data: 連線，僅用於單檔打包，多檔版本維持 `script-src 'self'`。
- 純規則模組（`engine.js`）不依賴 DOM 或儲存，方便測試。

## 7. 驗收項目
1. 單檔 `index.html` 可直接在瀏覽器開啟（以網址或 HTTP 伺服器），不需要安裝。
2. 完整流程：開始練習 → 作答 → 交卷 → 看解析 → 只重練錯題，全程沒有未捕捉的 JavaScript 錯誤。
3. 錯題重練的題目 ID 與錯題相同、選項順序改變、原紀錄不變。
4. 自動化測試：`npm run check`、`npm test`（31 項）、`npm run test:code`、`tests/browser.py`（18 組真實瀏覽器測試）全部通過。

## 8. 已知限制
- 題庫僅 32 題，重練可用題數有限。
- 資料只存在本機瀏覽器，換裝置前要先匯出備份。
- 瀏覽器清除網站資料會遺失紀錄。

## 9. AI 協助的紀錄
- 規格與功能擴充由使用者與 Claude 反覆討論後實作，每一輪改動都重新跑測試。
- 實作以既有的 `engine.js`／`app.js` 為基礎，新增 `wrongPlan` 純函式與單檔打包腳本。
