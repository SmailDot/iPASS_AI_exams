# 自適應學習規格

> 狀態：設計草案，尚未實作、驗證或校準。本文的數量、間隔、配額與升級門檻都是本專案的可調整預設，不是官方考試規定，也不是經實驗驗證的學習效果保證。

## 1. 目標：調整下一步，不替學習者貼永久標籤

同一個人可能會判斷模型情境，卻不會算指標；可能會手算，卻看不懂等價程式。因此不能只用「本章答對率」或一個總分控制全站。

以「細考點 × 任務類型」保存證據。例如分類指標拆為：

- 概念：分子與分母代表的群體。
- 計算：從數量或混淆矩陣求指標。
- 讀碼：辨認程式選取的元素及算式。
- 情境：依漏判、誤判等條件選擇指標。

每個細考點可有前置關係。例如陣列切片是部分 NumPy 讀碼題的前置，但不是理解所有模型概念的前提。不因讀碼失敗而阻止學習者閱讀其他章節。

## 2. 保存哪些證據

每個作答事件至少保存：

| 欄位 | 用途 |
| --- | --- |
| attempt_id、session_id、event_id | 區別首次與重做；重複交卷時去重 |
| question_id、question_version、content_hash | 固定當時實際看到的題目與答案版本 |
| family_id、template_id、variant_seed | 追蹤相近模板，避免換數字後冒充完全獨立證據 |
| skill_ids、task_type、difficulty | 細考點、概念／計算／讀碼／情境，以及人工初始難度 |
| selected_option_id、option_order | 以穩定選項 ID 計分，畫面 A/B/C/D 只負責呈現 |
| confidence、reason_text | 把握程度與理由；未填信心不假設是有把握 |
| aid_flags、explanation_seen_at | 區分閉卷、提示、看解析、搜尋、AI 或執行程式 |
| started_at、submitted_at、active_duration | 計畫與回顧使用；中途暫停和切至背景另行記錄 |
| asset_status、technical_issue、invalidated_at | 必要素材失敗的題目不能誤判成不會 |
| import_origin、schema_version | 區分本站事件、舊報告或自填紀錄 |

作答歷史採追加事件，不因更正答案或匯入新題庫覆寫舊紀錄。由歷史重新產生目前的學習摘要。使用者可要求清除自己的資料；刪除和重設需要明確確認。

舊 TXT 報告匯入先顯示題號、答案、信心與缺少欄位的預覽。只有相符的題庫版本及題號才能重新核對答案；未知題目以「舊報告提供的結果」顯示，不捏造題文或當成經本站獨立驗證的成績。

## 3. 錯因判斷的邊界

第一版不宣稱能自動讀懂所有自由文字。錯因來自題目設計時標註的常見誤選原因，加上使用者自選的卡點；這只能產生「可能錯因」。需有追問題確認，不能把選一個錯誤選項等同於確診某種迷思。

「理由正確但選項錯誤」由使用者或教學者標記；第一版不靠關鍵字硬判。這類作答的原始成績仍維持錯誤，但學習安排改成短題查核、選項核對，而不是直接退回整章初學。

| 證據 | 下一步預設 | 禁止的推論 |
| --- | --- | --- |
| 選不會或未答 | 一個前置短課及拆步驟題 | 不把未答一律解讀成概念错误 |
| 錯且有把握 | 提供反例、指出可能迷思，再出不同問法 | 不只重複原題和正解 |
| 對但猜測／不確定 | 換問法或要求中間結果確認 | 不直接標成穩定掌握 |
| 對且有把握 | 保留初步證據，隔開後出跨情境變體 | 不因一次答對跳過整章 |
| 手算對、讀碼錯 | 陣列索引與中間資料追蹤 | 不取消已成立的概念證據 |
| 看提示後答對 | 記為有輔助學習成功，另排未見題 | 不當成閉卷掌握 |
| 近期同一題重做答對 | 留下練習進步紀錄 | 不加入未見題成績 |
| 必要圖片／程式區塊未載入 | 暫停、修復或標為無效 | 不扣分、不更新能力 |

## 4. 學習狀態，不是通過機率

採可理解的狀態：`尚未測到`、`需要補基礎`、`初步掌握`、`跨情境待確認`、`延後複測已確認`。另附 `證據不足` 或 `待複習` 標記。

「延後複測已確認」初始規則提議：同一細考點至少有三個不同題族的有效閉卷答對，分布至少兩個學習日，其中至少一題為與先前成功任務不同的適用題型，且有一次在上次相關講解至少 24 小時後完成。近期仍有高信心錯誤時，先保留待確認標記。無合適題族或跨題型內容時，顯示資料不足，不硬湊證據。

這是保守的產品狀態門檻，不是心理計量的能力估計。信心只改變後續安排，不改變原始選擇題分數，也不因誠實填「猜測」懲罰使用者。

更高階的貝氏知識追蹤或題目反應理論可在有足夠、合適資料且做過校準後評估；首版不使用聽起來精準卻無根據的百分比。

## 5. 每組練習如何決定

### 篩選先於排序

先排除：未審查、已撤回、來源疑義未解、必要資產不可用、條件不足、版本不相容的題目。模考保留題不能流入日常練習池。已揭露解析的題目不能標為未見。

接著依細考點狀態排序：近期高信心錯誤、前置缺口、到期複習、未覆蓋考點。所有推薦都產生可顯示的理由與選題規則版本。

### 建議的初始配額

12 題的日常練習組可以先安排 6 題弱點／前置補強、3 題到期複習、3 題尚未覆蓋的內容。若某個池沒有足夠題目，依序借用其他池並向使用者說明；不能默默把重複題算成新題。短課與休息另外計入本次時間。

這是學習配額，不是正式試卷配分。使用者可以切換為指定章節、程式專練或固定藍圖模考。

### 避免「只練弱點，其他地方全漏掉」

即使讀碼是主要弱點，也保留未覆蓋章節的配額。每週顯示四大主題與細考點的題目覆蓋及證據缺口，不把某章做過一題顯示成整章完成。

### 難度怎麼調

同一細考點跨兩個題族連續失敗時，下一組先降低推理步數並提供前置短課；不是只把數字變小。連續成功時，逐步移除提示、增加條件比較或改變任務型態。難度標籤起初由人工設定，待有可靠練習資料後再檢視，不把初始標籤當成經統計校準的難度。

一次練習開始後固定題目、選項順序、圖表、程式、答案與版本。自適應只作用於下一組，不能在使用者返回上一題時突然換題。

## 6. 間隔複習與時間安排

可先採 1、3、7、14 天的名義複習间隔作為可調整預設。答错時縮短間隔或拆解前置；重新答對後再逐步延長。這些間隔不是針對每個人最佳化的結論。

日程依使用者選擇的 15、30、60 或 120 分鐘生成。答題較慢只影響本次題量估計，不扣能力分。學习期限由使用者設定；到期前以全科缺口與未見混合題為主，但不承諾特定考試結果。

網站只顯示當次／下次安排，不在未獲同意時傳送通知或建立外部行事曆事件。

## 7. 變體不是重複問同一題

題庫同時記錄考點、題族與推理任務。可用的變化包括：

1. 同概念換資料：重新驗算結果與干擾選項，避免一樣的數字答案。
2. 正向求值改反推：給定指標與部分數量，推缺少的量；須確認解唯一且符合非負整數等條件。
3. 情境條件改變：從強調漏判改成限制誤報，使適用答案可能改變。
4. 文字改程式：以同一概念追蹤中間變數、輸出或錯誤位置。
5. 程式任務改變：從求輸出改成最小修正、shape 相容性、驗證流程判斷。
6. 圖表／流程變化：題目、圖片、原始數據、答案與解析共同產生，不能只換題文留下舊圖。

參數化模板須限制合法參數域、驗證唯一答案，並在發布前物化成可追蹤的實例或提供等強的驗證策略。初版優先發布有限數量、驗證過的實例，不承諾無限出題。

去重至少包含正規化題文雜湊、模板與題族記錄、來源關聯及人工檢查。同一模板換數字屬練習變體，但不計為完全獨立題族。改變措辭或換產業名稱本身不構成新的推理任務。

## 8. 驗收與模考

練習正確率、首次未見題正確率、同題重做、提示後答對、跨情境複測分開呈現。

正式模擬模式使用事先固定的主題／題型／難度藍圖，不因前面答错就降低後面題目難度。日常自適應練習的分數不得直接與固定藍圖模考相提並論。

暫定備考驗收可為：不同日期的三回未見混合模考各至少 80 分、平均至少 85 分，另檢查程式分項至少 75%。這只是自訂的練習門檻，不是官方達標標準或正式分數推估。題庫不足或回合有無效題時，不得顯示已達此門檻。

保留池盡量以題族而非只以題號切分。接受過的講解與所有已顯示題目皆記錄曝光，避免把近似模板再當成獨立測量。公開靜態程式碼中的答案仍可被查看，因此本產品是誠實自測，不是防作弊考試系統。

## 9. 個人資料與 AI

所有個人事件、筆記與報告預設保存在本機，不提交公開 GitHub、Issue 或測試截圖。首次冷啟動可自行匯入舊報告；公開示範使用合成資料。

第一版的動態安排不需要 AI API。未來 AI 助教可解釋教材、協助讀碼或提出新題草稿，但必須区分引用、推論與未確認內容；不能將即時生成答案直接加入正式計分題庫。

自由文字理由若要傳送外部 AI，須另行告知內容、目的與成本並取得同意。API 金鑰不進公開儲存庫或前端建置產物。

## 10. 必須寫成測試的案例

- 相同事件重送不得重複增加學習證據。
- A/B/C/D 重排後，選項 ID、答案與解析仍一致。
- 答對但看過提示，不進閉卷證據池。
- 同一題重做滿分，不增加未見題數。
- 同模板換數字，不冒充三個獨立題族。
- 技術失效或已撤回題，不扣分、不觸發降級。
- 理由與選項矛盾只標記待確認，不任意變更原始成績。
- 局部錯誤不清空其他任務型態的正確證據。
- 長期弱點存在時，仍有未覆蓋章節配額。
- 題庫不足時明示不足，不降低驗收標準。
- 模考進行中不改題、不改難度、不替換答案。
- 題目更新後，舊作答仍能還原原版本；撤回影響可重新計算且有紀錄。
